# Complete game discovery

The user selected a complete catalog by default with an explicit Korean-support filter. The existing Korean home shows only 165 native games despite the provider catalog containing 2,846 games. The page-number control jumps from 2 to 7 without explaining the gap.

Use the existing Astro portal and provider snapshot. Separate interface language from native game availability in listings and search. Preserve native-only game detail routes, existing editorial indexability, iframe URLs, CLID and stored favorites/recent history. Cross-language cards identify the actual game language and link to a valid supported detail route.

Replace the large spotlight and repeated discovery shelves with a compact introduction, visible catalog totals, genre navigation, support filter and a single card grid. Use a warm light canvas, dark navigation, green accents and readable thumbnails. Show item ranges, sequential nearby page numbers and explicit ellipses. Mobile navigation must remain usable without overflow.

Alternatives: retaining native-only homes with an additional global tab was rejected by the user's selection. Creating unsupported Korean game routes would falsely imply language support. The selected approach reuses supported routes and statically paginates the complete catalog in every UI language.
