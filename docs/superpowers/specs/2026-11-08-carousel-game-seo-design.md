# Featured carousel and game detail SEO

The user requests an automatically rotating recommendation on the existing Steam-inspired home and more useful game descriptions with SEO applied to every detail page.

Keep the current renderer, catalog, authored guides, translations, publisher attribution and hosting. Show up to six curated recommendations in the existing space. Advance every six seconds; provide previous, next, position and pause controls. Pause on hover/focus, hidden documents and off-screen placement; respect reduced motion. Keep the first slide usable without JavaScript and reserve the same dimensions for all slides.

Improve details through the existing shared renderer and locale player shells. Preserve authored prose first. Display the complete provider description and instructions in the matching English/Russian source language; in other languages use saved localized introductions, source-confirmed input/control and gameplay labels, and localized device/language information. Retain an explicitly attributed expandable original. Do not infer unsupported keys, actions, walkthroughs, release dates, popularity or success rates. These factual additions improve navigation and play preparation; they are not newly reviewed editorial guides.

Add visible section navigation, structured controls/progression and compatibility information. Give dynamic locale shells the same factual sections through trusted catalog data. Keep per-game titles/descriptions, WebPage and VideoGame entities distinct, localized breadcrumbs and social metadata aligned with visible content. Audit all static game routes and client shells. Preserve current authored-guide indexability and sitemap gates; extra boilerplate or machine-derived labels must not make a thin page indexable.

Approaches: a third-party slider would add a dependency for a few controls; a client-only carousel would hide recommendations from non-JavaScript readers. Use server-rendered slides and a small timer. Generating long generic SEO paragraphs would not add game-specific evidence; reuse source-confirmed game data and clearly distinguish reviewed guides from provider information instead.

Defaults chosen for this implementation: six slides, six-second interval, no third-party requests before Play, no new dependencies or paid translation service, no bulk indexability expansion.
